## 📆 Clase #3 — 21 de Septiembre de 2026

- 📝 Resumen de la clase

  En esta sesión creamos nuestro **primer programa en Java**. Conocimos los principales elementos del entorno de desarrollo **IntelliJ IDEA** y analizamos la estructura básica de un programa, prestando especial atención al concepto de **clase** y a los elementos que la componen.

  ### 🎯 Objetivos cumplidos

    - Crear y ejecutar un primer programa en Java
    - Identificar los principales elementos del IDE
    - Comprender la estructura básica de un programa Java
    - Introducir el concepto de clase
    - Reconocer los elementos principales de una clase

  ### 📚 Contenido

  Comenzamos la clase creando un nuevo proyecto en **IntelliJ IDEA** y repasando los elementos más importantes del entorno de desarrollo. Vimos cómo se organiza un proyecto, dónde se encuentran los archivos de código y qué herramientas ofrece el IDE para escribir, ejecutar y revisar nuestros programas.

  A continuación, desarrollamos nuestro **primer programa en Java**. Analizamos su estructura principal y observamos cómo se organiza el código dentro de una clase. También identificamos el punto de entrada del programa y el proceso necesario para ejecutarlo y comprobar su resultado.

  Hicimos especial hincapié en el concepto de **clase** como elemento fundamental de Java. Explicamos que una clase define la estructura y el comportamiento de los objetos, y revisamos sus componentes principales, como el nombre, los atributos y los métodos. Esta introducción servirá de base para comprender los próximos contenidos de programación orientada a objetos.

  ### ✅ Actividades realizadas

    1. Creación de un nuevo proyecto en IntelliJ IDEA
    2. Exploración de los principales elementos del IDE
    3. Escritura y ejecución del primer programa en Java
    4. Análisis de la estructura básica del programa
    5. Introducción al concepto de clase y a sus elementos

  ### 📌 Recordatorios

    <aside>

  Es importante familiarizarse con la organización del IDE y comprender la estructura básica de una clase en Java, ya que estos conceptos serán la base de los próximos ejercicios y contenidos del curso.
