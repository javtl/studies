## 📆 Clase #4 — 22 de Septiembre de 2026

- 📝 Resumen de la clase

  En esta sesión trabajamos el concepto de **variable** en Java, sus diferentes tipos y su uso dentro de los programas. También practicamos las **impresiones por consola** para mostrar información y comprobar el resultado de nuestras instrucciones.

  ### 🎯 Objetivos cumplidos

    - Comprender qué es una variable y para qué se utiliza
    - Conocer los principales tipos de datos
    - Declarar y utilizar variables en Java
    - Mostrar información mediante impresiones por consola
    - Comprobar los resultados de la ejecución de un programa

  ### 📚 Contenido

  Comenzamos estudiando el concepto de **variable** como un espacio de memoria en el que se almacena un valor que puede utilizarse durante la ejecución del programa. Vimos cómo declarar variables, asignarles valores y utilizarlas en diferentes expresiones e instrucciones.

  A continuación, repasamos los principales **tipos de datos** utilizados en Java y las diferencias entre ellos, teniendo en cuenta el tipo de información que permiten almacenar. También practicamos la elección del tipo adecuado según el valor que necesitábamos guardar.

  Por último, trabajamos con las **impresiones por consola** para mostrar mensajes y valores de variables. Estas instrucciones nos permiten observar el comportamiento del programa y comprobar que los resultados obtenidos son los esperados.

  ### ✅ Actividades realizadas

    1. Explicación del concepto de variable
    2. Revisión de los principales tipos de datos
    3. Declaración y uso de variables en Java
    4. Realización de impresiones por consola
    5. Comprobación de resultados durante la ejecución del programa

  ### 📌 Recordatorios

    <aside>
