## 📆 Clase #2 - 16 de Septiembre de 2026

- 📝 Resumen de la clase

  En la sesión de hoy hemos diferenciado los conceptos de **frontend** y **backend**, y hemos repasado la diferencia entre **lenguajes de alto nivel** y **lenguajes de bajo nivel**.

  Además, hemos revisado las **instalaciones necesarias** para trabajar con **Java** y usar **IntelliJ** como IDE. Por último, hemos visto qué es **GitHub**, para qué se utiliza y las bases para empezar a trabajar con repositorios.

  ### 🎯 Objetivos cumplidos

    - Comprender la diferencia entre frontend y backend
    - Distinguir lenguajes de alto nivel vs. bajo nivel
    - Revisar e instalar el entorno necesario para trabajar con Java
    - Configurar IntelliJ como entorno de desarrollo
    - Introducción a GitHub y a su uso básico con repositorios

  ### 📚 Contenido

  Comenzamos la clase aclarando qué parte del desarrollo se considera **frontend** (interfaz y experiencia de usuario) y qué parte corresponde al **backend** (lógica, datos y servidores), y cómo se comunican ambas capas.

  Después, hablamos sobre los **lenguajes de programación de alto nivel** y **bajo nivel**, entendiendo sus diferencias en términos de cercanía al hardware, abstracción, facilidad de uso y casos habituales.

  A continuación, revisamos las **instalaciones y configuraciones** necesarias para poder trabajar en local con **Java** (JDK) y preparar **IntelliJ** como IDE para las próximas prácticas.

  Cerramos la sesión con una introducción a **GitHub**: qué es, para qué sirve en proyectos reales y cómo se organiza el trabajo mediante **repositorios** (creación, gestión y conceptos básicos de uso).

  ### ✅ Actividades realizadas

    1. Explicación y ejemplos de frontend vs. backend
    2. Comparación de lenguajes de alto nivel y bajo nivel
    3. Revisión del entorno de desarrollo para Java (JDK)
    4. Configuración/puesta a punto de IntelliJ como IDE
    5. Introducción a GitHub y demostración de repositorios
