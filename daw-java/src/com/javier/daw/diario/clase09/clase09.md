## 📆 Clase #9 — 6 de Octubre de 2026

- 📝 Resumen de la clase

  En esta sesión introdujimos el concepto de **objeto** en Java y revisamos los **elementos que componen una clase**. También comenzamos a crear **estructuras básicas con constructores sencillos**, relacionando la definición de una clase con la creación de sus objetos.

  ### 🎯 Objetivos cumplidos

    - Introducir el concepto de objeto
    - Comprender la relación entre clase y objeto
    - Reconocer los elementos principales de una clase
    - Crear estructuras básicas de clases en Java
    - Introducir el uso de constructores sencillos

  ### 📚 Contenido

  Comenzamos trabajando el concepto de **objeto** como una instancia de una clase. Diferenciamos la clase, que define una estructura y un comportamiento, de los objetos que se crean a partir de ella.

  A continuación, revisamos los **elementos de una clase**, como los atributos y los métodos, y situamos el **constructor** dentro de su estructura. Relacionamos estos elementos con los datos y las acciones que puede tener un objeto.

  Por último, creamos **estructuras básicas con constructores sencillos** para introducir cómo se inicializan los objetos. Esta primera aproximación nos permitió conectar la definición de clases con su utilización en un programa.

  ### ✅ Actividades realizadas

    1. Introducción al concepto de objeto
    2. Explicación de la relación entre clase y objeto
    3. Revisión de los elementos principales de una clase
    4. Creación de estructuras básicas en Java
    5. Uso de constructores sencillos

  ### 📌 Recordatorios

    <aside>

  Es importante distinguir entre una clase y un objeto, e identificar la función de los atributos, los métodos y los constructores. Los constructores permiten inicializar los objetos al crearlos y serán una base para las próximas prácticas.

    </aside>
